КОМПАНІЯ (Company)

ID: Унікальний ідентифікатор (UUID або CUID).
Name: Публічна назва бізнесу (наприклад, "LynxAI").
Slug: Коротке ім'я для URL (наприклад, reeltor). Це дозволяє робити посилання типу [lynx-crm.com/reeltor/dashboard](https://lynx-crm.com/reeltor/dashboard).
BusinessURL: Пряме посилання на Instagram, сайт або Telegram-канал бізнесу.
Status: Стан компанії (Active / Trial / Suspended / Banned).
CreatedAt: Точна дата реєстрації бізнесу в системі.
OwnerID: Зв'язок з користувачем, який створив цю компанію (Адмін).

-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_
ПІДПИСКИ (Subscriptions)

CompanyID: Зв'язок з таблицею Компаній (одна підписка на одну компанію).
PlanType: Рівень підписки (Free / Starter / Business / Pro).
Price: Сума, яку платить клієнт (наприклад, 500 грн/міс).
Currency: Валюта (UAH / USD).
Status: Поточний фінансовий стан (Paid / Unpaid / Expired).
StartDate: Дата початку поточного оплаченого періоду.
EndDate: Дата, коли доступ має бути заблокований.
AutoRenew: Чи ввімкнено автоматичне списання коштів.

-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_
КОРИСТУВАЧІ (Users)

ID / Email / Password: Стандартні дані для входу.
Role: Поле з роллю (CREATOR / ADMIN / MANAGER).
CompanyID: Зв'язок з Компанією.
У Manager — завжди вказано ID компанії, де він працює.
У Admin — вказано ID його головної компанії (або масив ID, якщо компаній декілька).
У Creator — це поле пусте (null), бо він над системою.
TG_Contact: Прямий юзернейм або ID у Telegram для швидкого зв'язку.
LastActive: Коли користувач останній раз заходив у систему (важливо для аналітики активності).

-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_-_
Ліди (Leads / Clients)

Робочі дані, які наповнюють менеджери.
ID: Унікальний номер заявки.
CompanyID: Кому належить цей лід (щоб менеджери іншої компанії його не бачили).
ManagerID: Хто відповідальний за цей продаж.
Status: Стан (New / Active / Completed / Banned).
Telegram: його нікнейм або id
Details: Короткий опис шо він хоче.
UpdatedAt: Дата останньої зміни статусу.
